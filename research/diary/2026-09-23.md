## Findings from monitoring rep1 (all measured unless labelled)

1. **nextpnr has no timeout.** `tools/eval/fpga.py` `run_seed` awaits nextpnr unbounded, and the fpga phase gate admits one slot at a time. r14s2 spent about 45 min in placement, blocking r14s1's FPGA stage. It routed, and it won. A design that never routes would hang the rep with no failure recorded. Fix: per-seed timeout, recording the seed as a placement failure.
2. **Codex `/tmp` is shared and writable.** A round 7 implementer wrote `/private/tmp/bench_hyp_r7/`, and the round 15 scribe found it later. The round 4 scribe searched `/private/tmp` and read a Claude Code monitor output file. It held only this rep's own events, so there was no leak into the rep, but it is an escape from the clone. With `--parallel` reps this is a cross-rep channel. Fix: `exclude_slash_tmp` / `exclude_tmpdir_env_var` in the Codex sandbox config, and a per-clone `TMPDIR`.
3. **The clone's riscv-formal is a symlink into the main checkout.** The Codex sandbox blocks writes there, so agents copied 140 to 225 MB of riscv-formal into `.tmp` for each self-check (the clone's `.tmp` reached 3.4 GB). Harness formal runs write through the symlink into the shared tree; that is serialized by the machine lock but still shared. Fix: a per-clone riscv-formal (clonefile copy), made writable to the agent, still fingerprinted.
4. **Scribe transcripts are not collected** into `agent.log`, only into the Codex session store. Telemetry gap. Token totals may undercount (untested).
5. **RVFI logic is timed.** `fpga/core_bench*.sv` XOR-reduces RVFI outputs into the LED, so verification-only logic is synthesized and constrains Fmax. r2s0 was accepted for segmenting the 64-bit RVFI order counter. That is a contract decision (don't-touch file), left for the operator.
6. **ALTOPS formal does not check multiplier/divider arithmetic per candidate.** Every accepted candidate passed cosim (real arithmetic on the ISS-compared programs), but the pristine `test_alu.py` is not run as a gate. Fix: run it from the contract copy against each candidate.
7. **Area is not scored.** r13s1 (register file to LUT-RAM) cut LUT4 by 41% (5713 to 3337) and scored as a plain regression (Fmax 162.3). That is correct under the scalar contract, and a Pareto data point.
8. **The main checkout's `.gitignore`** lacks `bench/**/agent.full.log.gz` until `fix/eval-hardening` merges. The full transcript must not be staged from main.
9. **Naming:** `best_round` in the summary JSON is the journal index (43), not the round (14).
